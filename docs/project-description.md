# Космический бой

Космический бой - сервер на Go, который принимает приказы игроков и меняет состояние их кораблей. Работающая версия запускает одну игру для двух участников. Игрок получает токен для этой игры, отправляет приказ своему кораблю и видит результат движения в снимке состояния. Приказ чужому кораблю сервер отклоняет.

Сейчас доступны три действия: `StartMove` задает скорость, `Advance` сдвигает корабль на один шаг, `StopMove` останавливает его. Игра не идет сама по таймеру: каждый шаг вызывается отдельным приказом. В игровом ядре также есть поворот, стрельба и поиск возможных столкновений, но локальный сервер пока не связывает их в правила полноценного боя. Попадания, победитель и повтор боя еще не реализованы.

Состояние одной игры меняет один работник. Приказы попадают в его очередь; запрос снимка проходит через ту же очередь и видит результат предшествующих действий. Публичное имя приказа переводится через список разрешенных операций в фабрику команды. Клиент не может передать произвольный ключ IoC. Перед постановкой приказа сервер проверяет токен, игру и владельца корабля.

Локальный запуск объединяет авторизацию и игру в одном процессе. Отдельная программа авторизации в репозитории есть, но общего каталога игр между двумя процессами пока нет. Данные игры, очередь и ключи токенов живут только до остановки сервера. Ответ `202` означает, что приказ поставлен в очередь; итог конкретного приказа клиенту пока недоступен. Поэтому повтор после сетевой ошибки может выполнить `Advance` дважды. Следующее изменение должно связать приказ с идентификатором, результатом и правилом повтора.

Как запустить рабочую версию и повторить сценарий двух игроков, описано в [README](../README.md). [Проектный план](project-plan.md) содержит процессы, схемы, принятые решения и оставшиеся этапы.
